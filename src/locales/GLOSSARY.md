# Translation glossary

Terms that must be translated consistently across every namespace. Translators: pick the everyday banking term a consumer app in that language would use, and keep it the same everywhere.

| English | Meaning in this app |
|---|---|
| Account | A bank, card, loan, investment or retirement account the user tracks. |
| Card | A debit/credit card attached to an account (identified by its last four digits). |
| Transaction | One row of money movement on an account. |
| Expense / Income / Refund / Transfer | The four transaction types. A refund is money coming back for an earlier expense; a transfer moves money between the user's own accounts and counts as neither income nor expense. |
| Category | The spending or income bucket a transaction belongs to (Groceries, Salary…). |
| Company | The merchant or payer on a transaction. |
| Subscription / Recurring series | A repeating charge detected from transactions (Netflix, rent). "Series" is the technical name for one detected stream of payments. |
| Merchant rule | A pattern that matches bank descriptions to a merchant/subscription. |
| Type rule / Classification rule | A pattern that decides a transaction's type (expense/income/refund/transfer). |
| Budget / Budget plan | Monthly spending limits per category. |
| Carry-over | Unused (or overspent) budget rolled into the next month. |
| Fund | Savings set aside for a project or trip, linked to a budget category. |
| Project | A home project or goal with tracked costs. |
| Trip | Travel with tracked costs. |
| Loan | Borrowed money with principal, interest and payments; "deferred interest" is a promotional period after which back interest is charged. |
| Principal / Interest | The two parts of a loan payment. |
| Pay-by date | The last day to pay off a deferred-interest loan before interest is charged. |
| Net worth | Assets minus debts across accounts. |
| Default currency | The currency every cross-account total is shown in. |
| Exchange rate | The user-entered rate converting one currency into the default currency. |
| Opening balance | The account balance on the day tracking started. |
| Credit limit | The spending cap on a credit card. |
| Notification / Reminder / Alert | Notifications are the whole feature; reminders are user-created, alerts are generated by scans. |
| Snooze / Dismiss / Mark done | The three ways to handle a notification. |
| Import (CSV) | Loading bank-exported transactions from a file. |
| Duplicate | A transaction that already exists (detected by hash). |
| Sync / Cloud backup | Saving the database to Google Drive or OneDrive. |
| Lock / Unlock | Protecting the database with the password / entering it. |
| Primary user | The main person using this database; other household members are users too. |
| Sample data | Demo data loaded into a new database for exploring the app. |
| SQL Query | The read-only page where users run SELECT statements. |
| Developer Console | The in-app log viewer. |
| Local AI | The on-device assistant running a GGUF model in the browser. |
